# Consumer Behaviour and Spending Pattern Analytics

## Project Overview
This project focuses on analyzing consumer behaviour and spending patterns using data analytics techniques. The objective is to identify customer trends, purchasing habits, and spending insights from retail and transaction datasets.

## Objectives
- Analyze customer purchasing behaviour
- Identify spending trends
- Perform customer segmentation
- Create visual dashboards
- Generate business insights using data analytics

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Project Structure
data/ → datasets  
notebooks/ → Jupyter notebooks  
scripts/ → Python scripts  
dashboard/ → dashboard files  
reports/ → reports and documentation
